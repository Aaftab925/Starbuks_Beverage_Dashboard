# ☕ Starbucks Beverage Dashboard | Power BI

## 📌 Project Overview
This project is an interactive Starbucks Beverage Dashboard created using Microsoft Power BI. It provides insights into Starbucks beverage categories, nutritional information, caffeine content, and beverage distribution.

The dashboard helps users explore beverage data and understand different product characteristics through interactive visualizations.

## 🎯 Key Performance Indicators (KPIs)
- Total Beverages
- Total Calories
- Total Sugars (g)
- Average Caffeine

## 📊 Dashboard Visualizations
- **Beverage Category Analysis:** Analysis of beverage categories.
- **Beverage Distribution:** Donut chart showing total beverages by category.
- **Calories Analysis:** Area chart showing calories across beverage categories.
- **Average Caffeine Analysis:** Bar chart comparing average caffeine across categories.
- **Country Analysis:** Filled map visualization.
- **Interactive Filters:** Beverage Preparation and Protein (g) slicers.

## 🛠️ Tools & Technologies
- Microsoft Power BI

## 💡 Project Objectives
- Analyze Starbucks beverage categories.
- Explore nutritional values of beverages.
- Compare calories, sugars, and caffeine.
- Understand beverage distribution by category.
- Create an interactive and user-friendly dashboard.
